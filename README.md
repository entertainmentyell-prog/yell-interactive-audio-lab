# Yell Entertainment — Interactive Audio Labs

Static site, no build step. Pages: `index.html` (portal), `sound-space.html`, `phase-wheel.html`.

## Run locally
Open `index.html` in a browser (or `npx serve`).

## Deploy to Vercel
- CLI: `vercel --prod`
- Or import the repo at vercel.com (Framework Preset: Other).

## Asset
Keep the logo file named exactly `yell-logo.png` in the project root.
